# REVISAO_TEXTO.md

Passei pelos arquivos dessa versão procurando texto muito formal, repetitivo ou com jeito de documentação automática.

Também conferi os comentários dos arquivos CSS e JavaScript.

O que foi ajustado:
textos mais curtos
frases mais diretas
menos repetição
instruções escritas como conversa entre a equipe
sem texto falando de IA
sem sequência de dois hífens solta nos arquivos

Não coloquei erro de português forçado. Preferi deixar o texto mais natural usando coisas como "pra", "a gente", "dá pra" e frases menos formais. Fica humano sem parecer erro colocado de propósito.
